# Review Room ↔ Engineering Evidence Journey UX Polish

## Purpose
Improve student orientation and simplicity across the two-room workflow without changing evidence intelligence.

## UX contract
- Review Room is the conversation home.
- Engineering Evidence is the saved source notebook.
- Both rooms visibly state where the student is.
- Snapshot relationship is explicit: same snapshot, newer saved Evidence snapshot, completed review, or no active review.
- Button-triggered repository search is displayed as **Find supporting evidence** rather than exposing the internal search instruction as student-authored prose.
- The detailed bounded-search instruction is still sent to the reviewer.
- Inspect, search, discuss, challenge, resolve, browse, and start-new-review remain distinct actions.
- Mobile layouts stack finding actions into full-width controls.

## Frozen engineering boundaries
This revision does not change retrieval, provenance, bounded discovery, analysis contracts, finding-state authority, lifecycle state, grading semantics, or repository interpretation.
