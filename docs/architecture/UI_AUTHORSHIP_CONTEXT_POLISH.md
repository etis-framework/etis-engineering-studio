# UI Authorship & Review Context Polish

This revision closes remaining student-facing UX issues found in production smoke testing.

## Invariants
- Button-triggered machine instructions are never displayed as though the student authored them.
- A student's unfinished draft is never overwritten by a button action.
- "Other concerns in this review" appears only when review context exists.
- Previous-snapshot changes are presented once with finding and evidence-area counts labeled separately.
- Aggregate evidence surfaces do not pretend to have one inspectable source.
- No retrieval, provenance, lifecycle, grading, or reviewer-engine contract changes.
