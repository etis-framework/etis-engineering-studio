# React/Vite UI source area

The current production Wave 1 UI is **not** built from this directory. It is served directly by FastAPI from `apps/api/app/static/`.

This directory remains reserved for a possible future React/Vite split if the product later benefits from a separately built frontend. A frontend split is an architectural change and must not be assumed from the presence of this directory.

Normal local development and production deployment do not require Node.js for the current UI.
