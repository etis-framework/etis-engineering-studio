The Wave 1 course model was derived from the authoritative COMP 330 Fall 2026 materials provided by the instructor, including:

- A1-A6 detailed assignment packages.
- Phase-Gate Engineering Review Rubric (A1-A4).

- Team Project Overview and CampusConnect Project Brief.
- Team Operating Model and Cycle Expectations.
- Team Repository Setup Guide.
- GitHub Engineering Workflow Guidance.
- Repository Structure and README Guidance.
- Team Peer Evaluation Form.
- Definition of Done and other supporting course guidance.

## Source precedence encoded in the Studio

1. Sakai: required course work, dates, grading, submission expectations.
2. GitHub: authoritative team engineering evidence and workflow history.
3. ETIS: broader professional reference used to deepen judgment without expanding the assignment.

## Known source cleanup notes

The instructor has already identified/recorded assignment-package cleanup items (for example, several tag-command/order/copy-forward defects). The Studio course model uses the intended phase semantics rather than reproducing those obvious copy-forward errors.
